# KhmerDub - Release Notes

## Version 1.0.1 (AI Dubbing Studio Release)
- **Khmer AI Dubbing Studio**: Dedicated AI video dubbing studio tab with support for male (`km-KH-PisethNeural`) and female (`km-KH-SreymomNeural`) Khmer speech synthesis.
- **Audio Ducking & Tempo Sync**: Auto-ducking original video track (-15dB) with automated Khmer speech tempo fitting.
- **Khmer Subtitle Renderer**: Native `Battambang-Regular.ttf` font subtitling with hard-coded burn options.
- **Multi-Platform Downloader**: High-speed video downloader for YouTube, Facebook, TikTok, and web streams.

## Version 1.0.0 (Initial Release)
- **Native Android KhmerDub App**: Multi-platform video & Khmer movie downloader.
- **In-App Media Player**: Built-in player with HTML5 localfile stream interceptor.
- **Web Sniffer Browser**: Integrated media sniffer browser for stream detection.
- **Auto-Updater Engine**: 1-click update checker.
